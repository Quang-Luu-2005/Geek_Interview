\section{Load Interpretation}
The stated peak of 300--500 booking requests per minute is approximately 5--8.3 booking requests per second. Therefore, the primary performance concern is not raw throughput but hot-row contention, transaction duration, and behavior under bursts.

\section{Optimization Priorities}
\begin{enumerate}
  \item keep booking transactions short;
  \item use correct indexes for lookup and expiry scans;
  \item avoid external network calls inside the DB transaction;
  \item separate expected sold-out/voucher conflicts from infrastructure failures;
  \item scale stateless API instances only after measuring database contention.
\end{enumerate}
